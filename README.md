# Мой первый сайт на HTML и CSS

Это мой первый проект в веб-разработке, созданный по пошаговому видео-уроку. Сайт представляет собой простую статическую веб-страницу, свёрстанную с нуля для закрепления основ.

## 🎓 Обучение

Проект выполнен в рамках урока **"Верстка сайта с нуля"** от автора **Web Skills**.
*   **Ссылка на урок:** [Верстка сайта с нуля | Полное руководство по HTML и CSS для новичков](https://youtu.be/Veo9TWOh-Q0?si=NDYGWF8QxBpUWExA)

## 🚀 Технологии

*   **HTML5** – семантическая разметка страницы
*   **CSS3** – стилизация и оформление элементоd
